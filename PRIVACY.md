# Privacy Policy – New Tab Extension

Last updated: 24 May 2026

New Tab is a privacy-first Chrome extension.

## Data Collection

This extension does not collect, transmit, store externally, sell, or share user data.

## Local Storage

The extension uses Chrome local storage only to save:

- Theme preferences
- Pinned shortcuts
- User settings

All data remains locally in the browser and is not sent to any external server.

## Third Parties

This extension does not use analytics, telemetry, advertising SDKs, or third-party tracking services.
